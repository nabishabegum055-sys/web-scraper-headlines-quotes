# 🕷️ Web Scraper for Headlines & Quotes

A beginner-friendly Python web scraping project developed as part of my **InternCircle Python Internship – Task 4**.

## 📌 Project Description

This project uses Python to fetch data from a website and extract useful information from its HTML content.

The application uses the `requests` library to send an HTTP request and `BeautifulSoup` to inspect and extract quote information from the webpage. The extracted data is formatted and saved as a JSON file.

## ✨ Features

- 🌐 HTTP request handling
- 🔍 HTML tag inspection
- 📝 Quote and author extraction
- 📊 Data formatting
- 💾 JSON file storage
- ⚠️ Error and connection handling

## 🛠️ Technologies Used

- Python 3
- Requests
- BeautifulSoup4
- JSON
- HTML Parsing
